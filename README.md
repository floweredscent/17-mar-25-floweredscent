# Simple Square Mathematic Calculator - RevoU **Fundamental Course Software Engineering Mini Project**

#### 📌 Goal

The goal of this mini project was to create a website of Square Mathematic Calculator as a way to practice the main responsibilities of a software engineer. This website allows users to calculate the area and the perimeter of squares and rectangles.

---

#### ⚙️ Workflow

1. **Requirement Analysis:** Identified the need for a simple calculator to compute the area and perimeter of a square and a rectangle.
2. **System Design:** The area and the perimeter are calculated using the standard formula:
    
    **Square:** 
    
    $$
    Area=s2
    $$
    
    $$
    Perimeter=4s
    $$
    
    **Rectangle:**
    
    $$
    Area=length × width
    $$
    
    $$
    Perimeter=2(length+width)
    $$
    
    The system flow includes input → validation → calculation → result display.
    
3. **Implementation:** he application is developed using:
    - HTML: Structure of the application
    - CSS: Styling and responsive layout
    - JavaScript: mathematical calculation and interactivity
4. **Testing and Evaluation** – Tested and evaluated the calculator with various input values to ensure accurate results and proper input validation.

---

#### 🌟 **Key Features**

- Calculate the area and perimeter of a square and a rectangle
- User input for side or length and width values
- Instant calculation and result display
- Input validation for empty or invalid values
- Simple and responsive user interface
